# 🌾 Agriculture Prediction System

## 📌 Project Overview

The Agriculture Prediction System is a Machine Learning project that predicts a suitable crop based on environmental and climatic conditions.

The system uses agricultural data and Machine Learning classification algorithms to predict the most suitable crop.

## 🎯 Objective

The objective of this project is to use Machine Learning to predict suitable crops based on:

- Temperature
- Humidity
- Soil pH
- Rainfall
- Wind Speed
- Solar Radiation

## 🧠 Machine Learning Algorithms

The project uses:

- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Naive Bayes

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## 📊 Dataset

The dataset contains historical agricultural and climate information including:

- State
- District
- Crop
- Temperature
- Humidity
- Rainfall
- Soil pH
- Wind Speed
- Solar Radiation

The dataset contains 50,765 records and 20 columns.
